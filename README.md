# Bilingual landing page (sample)

A **sample / demo** landing page I built to show my front-end style. It is not for a real client and the company name is made up.

- Arabic (RTL) and English (LTR) with a one-click language switch
- Responsive layout (phone, tablet, desktop)
- Plain HTML, CSS and JavaScript, no libraries
- The contact form is a demo: it shows a message and sends nothing

Open `index.html` in a browser to view it.
